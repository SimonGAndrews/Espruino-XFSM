# Repository Licensing

This repository uses a simple path-based licence boundary.

## Licence Map

| Path | Licence |
| --- | --- |
| All files except the exception below | Mozilla Public License 2.0 (`MPL-2.0`) |
| `examples/` | MIT License |

The complete MPL-2.0 text is in [LICENSE](LICENSE). The MIT text applying to
`examples/` is in [examples/LICENSE](examples/LICENSE).

Third-party material keeps its upstream copyright, licence, and attribution
requirements. Those requirements are recorded in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) and, for an adapted example,
in the affected file. An upstream notice does not change the licence of
unrelated XFSM files.

Code fragments outside `examples/` follow the licence of the document that
contains them unless the fragment is explicitly marked otherwise.

When documentation is proposed to EspruinoDocs, the submitted prose and code
may be licensed separately under the terms required by EspruinoDocs. That
upstream contribution does not change this repository's path-based licence
map.
